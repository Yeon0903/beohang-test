# 버항 개발 백로그 — Codex 작업 순서

상태: [부분]=파일/코드 일부 존재, [미완]=현재 코드에 완성 확인 불가. 아래 순서는 추천 우선순위, 버전 번호 강제 아님.

## P0 기반 안정화·테스트 서버
- [ ] 기존 V3.0 코드 및 SQL 의존성 지도, 실제 적용된 DB 마이그레이션 목록 확인(읽기 전용부터).
- [ ] Git 초기화, ignore, 시크릿 스캔, 환경별 설정, 정적 검사/스모크 테스트, 오류 로그.
- [ ] 현 사이트/DB는 staging으로 지정하고 **운영용 사이트·Supabase 별도 신규 생성** 계획/절차 확립. 이미 실제 사용자 데이터가 있다면 이동 전에 데이터 감사와 분리 계획.
- [ ] staging은 테스트 전용 계정·가짜 데이터; production은 별도 인증 사용자·SMTP·OAuth 앱/콜백·API 키·DB/RLS·스토리지·호스트 주소.
- [ ] production은 로그인 제한 항상 켜기. staging에서는 테스트 계정에 한해 완화하는 안전한 방법 도입. 관리자 MFA 및 관리자 보호 강화.

## P1 SOOP 연동 (최우선 핵심 기능)
- [ ] SOOP 공식 개발자 문서, 승인, 허용 redirect URI, 지원하는 scope/user identity API 확인; 불가 기능은 솔직히 표시.
- [ ] 기존 `soop-auth.js`/callback의 테스트 경로 제거 또는 분리; `virhang-soop-auth` 서버 함수 구현·저장소 관리.
- [ ] 로그인한 버항 회원만 선택적으로 연결(버항 회원가입을 SOOP 로그인으로 대체하지 않음).
- [ ] server-side code exchange, state 검증, 필요 시 PKCE, 최소 권한, 토큰 안전 보관/회전, 오류 처리.
- [ ] SOOP 고유 ID 검증, 회원 1:1 유니크 제약, 중복 연결/탈취 방지, 계정 연동 해제, 개인 계정 삭제 대응.
- [ ] 연동 권한별 기능 접근 정책과 스테이징 E2E 테스트.

## P1 인증·관리자/데이터 보안
- [ ] 이메일 실제 발송/6자리 OTP 정책/만료·재전송 횟수 제한 및 계정 복구.
- [ ] 인증 세션 지속·로그아웃·기기별 세션 철회·회원 정보 수정·탈퇴.
- [ ] 실제 RLS 정책/SECURITY DEFINER 함수 권한/초대 없는 관리자 승격 불가 등 권한 테스트.
- [ ] 관리자 감사 로그, 관리자 변경 작업 확인, 복구·재활성화(소프트 삭제), 최고관리자 MFA.
- [ ] 로그인 공격 방어: 계정별·IP별 제한, CAPTCHA 조건부, 남용 모니터링.

## P2 음악·통계·랭킹
- [ ] 실 데이터 기반 공통 좋아요 저장 및 좋아요 순위.
- [ ] 기간별(실시간/일/주/월/년/역대/좋아요/신곡) 순위 정의 및 검증, 스냅샷/순위변동/NEW.
- [ ] TOP50(역대 TOP100), 랭킹 전체 재생, 마지막 선택 유지 검증.
- [ ] 30초 유효 재생, 새 재생마다 반복 카운트, seek/일시정지/백그라운드 제약, 악용 방지·집계 신뢰도 테스트.
- [ ] 곡 링크 및 메타데이터(원곡 YouTube 링크 포함), 등록/수정/소프트삭제/복구, YouTube/Shorts/SOOP 외부 재생 불가 예외.
- [ ] 공동 가수·늦은 가입·신원 검증·권한 로직; 크루/그룹/소속 자유 태그 추가·변경·삭제 및 소개.
- [ ] 검색/필터·추천·관련곡/신곡 정렬의 서버 연동.

## P3 회원·스트리머·어항
- [ ] 나의 어항: 플레이리스트, 좋아요, 즐겨찾기, 개인 곡별 재생수, 최근 재생, 청취량/랭킹/리캡.
- [ ] 플레이리스트 생성·수정·삭제·공개 범위·공유·연속재생/반복·랜덤·이어 듣기.
- [ ] 즐겨찾기 스트리머 신곡 알림(수신 설정·중복 발송 방지).
- [ ] 스트리머 프로필/소속·그룹/참여곡 TOP10, 스트리머 측 본인 곡 관리(서버 승인 규칙 유지).
- [ ] 어업 포인트/물고기 성장·꾸미기 규칙은 기획 확정 후 구현, 부정 적립 방지.
- [ ] 공지·문의·업데이트 내역, 회원 설정, 접근성 및 반응형(PC 완성 뒤 모바일/PWA).

## P4 운영 출시 준비
- [ ] 테스트 자동화 (Unit / RLS 통합 / 로그인-OAuth E2E / 재생 집계 / 모바일 기본 동작).
- [ ] 개인정보처리방침·약관·저작권/YouTube/SOOP 사용 정책 점검.
- [ ] DB 백업·복구 훈련, 모니터링·에러 알림·업타임, 장애 대응, 비용/쿼터 관리.
- [ ] 스테이징 검증→변경내역 리뷰→프로덕션 마이그레이션→배포→롤백 표준화.

## 이 프로젝트에서 명시적으로 제외한 기능
- 스트리머 랭킹; 노래 등록 요청; 잘못된 정보 신고; 재생 불가 신고. 사용자가 다시 요청하기 전까지 추가하지 않는다.
- 모바일/PWA/앱 개발은 PC 정식 완성 이후.
