# VirHang V3.0 전체 개발 백로그

갱신: 2026-10-23 KST. 사용자 최신 8단계 요청을 기준으로 이전 P0~P4 목록을 통합했다.

상태: **로컬 검증**은 테스트 범위에서만 통과, **부분**은 일부 구현, **대기**는 미구현/미검증이다. 원격 DB/배포 검증을 통과하기 전에는 출시 완료로 표시하지 않는다. 개발은 `codex-dev`에서만 진행하며 main/Pages/실제 Supabase 변경은 사전 승인이 필요하다.

1차는 S1-01/02, 2차는 곡 검증·privacy RLS·환경별 계정 제한을 구현했다. 실제 적용/원격 검증은 별도다. `SECURITY_PATCH_01.md`, `SECURITY_PATCH_02.md` 참조.

## 기존 문서의 부가 범위와 제외 항목

공지·문의·업데이트 내역은 후속 백로그로 보존한다. 스트리머 랭킹, 노래 등록 요청, 잘못된 정보 신고, 재생 불가 신고는 최신 요청에도 없으므로 계속 제외한다. 개인 청취 순위(S7-02)는 스트리머 랭킹과 별개다.
