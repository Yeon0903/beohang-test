# 기능 완료 기준 (Definition of Done)
- [ ] 이슈에 변경 내용/관련 파일/SQL/롤백 절차 기록.
- [ ] 기존 로그인/관리자/음악/가수 연결/재생/랭킹이 깨지지 않음.
- [ ] 일반 이용자는 관리 API 직접 호출해도 권한 없음(403 또는 RLS 거부).
- [ ] 공개 브라우저 번들·Git 기록에 서비스 비밀키/비밀번호 없음.
- [ ] staging 사용 시나리오(성공·실패·재시도·취소·중복 요청)를 실제로 통과.
- [ ] 운영 데이터 삭제 없음, 필요한 SQL은 백업/복원 방법 포함.
- [ ] 사용자 확인 없이 production DB/배포 변경 없음.
- [ ] SOOP 계정 연동은 공식 인증으로 검증한 고유 ID와 버항 로그인 세션에만 결합; 중복·CSRF·해제 시나리오 검증.
