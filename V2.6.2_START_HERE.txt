버항 V2.6.2 — 무료 개발용 회원가입 UI 시험

변경 사항
- 회원가입에 ‘인증번호 화면 미리보기 (메일 발송 안 함)’ 버튼 추가
- 미리보기: 3분 타이머, 재발급 버튼 초기화 동작을 실제 이메일 없이 시험
- 미리보기에서는 인증 완료/회원가입 불가능. 인증번호를 만들거나 회원 정보를 저장하지 않음
- Supabase 이메일 발송 제한 메시지 한국어 안내
- 기존 V2.6.1 음악/플레이어/회원 인증 서버 구조 유지

실행
1. 이 ZIP을 새 폴더에 해제
2. virhang-auth.js 맨 위의 PASTE_SUPABASE_PUBLISHABLE_KEY_HERE에 내 프로젝트의 공개 Publishable Key만 입력
3. 이 폴더 주소창에 cmd -> python -m http.server 5500 (포트 사용 중이면 기존 서버 종료)
4. http://localhost:5500 에서 회원가입 -> '인증번호 화면 미리보기'

주의
- 실제 인증 메일은 여전히 Supabase 기본 템플릿(링크)이며 메일 발송 제한이 존재합니다.
- 3분은 UI 타이머이며 서버 OTP 만료 설정이 아닙니다.
- 아직 정식 서비스 배포용이 아닙니다. 기존 데이터베이스 SQL/Edge Function 수정 필요 없습니다.
- 실서비스 전에 아이디 로그인 Rate limiting과 Auth/RLS, OAuth 연동, SMTP 등을 검증해야 합니다.
