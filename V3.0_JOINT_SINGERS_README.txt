버항 V3.0 — 공동 가수 추후 가입 / 노래 수정·삭제 실험판

1. 기존 Supabase DB 백업을 권장합니다. 기존 V2.6.9_PUBLISHED_TRACKS_SETUP.sql이 적용되어 있어야 합니다.
2. Supabase SQL Editor에서 V3.0_JOINT_SINGERS_LATE_SIGNUP.sql 전체를 한 번 실행하세요.
3. 새 ZIP을 별도 폴더에 풀고, 공개 Supabase 키를 확인하여 python -m http.server 5500으로 실행하세요.
4. 관리자로 로그인한 후 '관리자 페이지 → 참여 가수 계정 연결'에서 활동명과 확인한 가입 아이디를 연결하세요.
   먼저 해당 회원에게 스트리머 권한을 부여해야 합니다.
5. 기존 노래에 적힌 체비, 아이네, 비챤 등 가수별 이름을 자동으로 분리 기록합니다.
   가입 전에는 이름만 유지합니다. 가입 후 운영진이 신원을 확인한 뒤 연결하면 기존 곡에도 관리 권한이 생깁니다.
   절대 활동명과 버항 아이디가 같다는 이유만으로 자동 연결하지 않습니다(사칭 방지).
6. 수정/삭제는 카드 ⋯ 메뉴에서 가능하며, 서버 RLS로 강제됩니다. 등록자와 확인된 참여 스트리머, 운영진만 가능합니다.
7. 기존 곡 ID 유지: 계정 연결·권한 부여는 음악 레코드/재생 수를 변경하지 않습니다.

주의: 삭제 버튼은 소프트 삭제(공개 목록에서 숨김)이며 곡과 조회수 이력은 보존됩니다. 복구 UI는 아직 미구현입니다.
가입/연결 기능과 실제 DB에서는 테스트 전 백업하세요. SOOP 사이트 내부 플레이어는 별도 작업 중이며 이 버전에도 아직 구현되지 않았습니다.
기존 SQL에서 사용자별 role과 권한 함수가 누락된 경우 마이그레이션이 실패합니다.
