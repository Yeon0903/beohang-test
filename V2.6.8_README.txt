버항 V2.6.8 — 아이디 기반 스트리머 지정 / 관리자 메뉴

1. V2.6.7 파일을 기반으로 계정 관리자 메뉴를 추가했습니다.
2. 반드시 Supabase SQL Editor에서 V2.6.8_ADMIN_STREAMER_SETUP.sql을 실행해야 관리자 권한 조회 및 스트리머 지정 기능이 작동합니다.
3. virhang-auth.js에서 SUPABASE_PUBLISHABLE_KEY 설정을 프로젝트 자신의 공개 키로 입력하세요. service_role / secret 키는 절대 사용하면 안 됩니다.
4. Python 로컬 서버: python -m http.server 5500
5. 최고관리자 viradmin으로 로그인 → 왼쪽 '관리자 페이지' → 등록된 버항 아이디 입력 → 조회 → 스트리머 지정
6. SOOP 연동은 선택적이고 이 기능과 별개입니다.
7. 기존 노래 등록은 여전히 브라우저 로컬 저장 체험 기능입니다. 실제 Supabase 공유 음악 DB 쓰기/관리자 정책은 후속 개발이 필요합니다.
8. 로그인 시도 횟수 제한 해제 상태라면 공개 운영 전에 반드시 제한 복구 및 IP 기반 보안 추가가 필요합니다.
9. 사용자 role은 서버 함수에서 직접 확인합니다. 화면 숨김은 보조 UI일 뿐 보안 경계가 아닙니다.
